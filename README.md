# ORVEXION

The ORVEXION website is built with React and Vite.

## Run locally

```sh
npm ci
npm run dev
```

## Deploy

Pushing to `main` builds and deploys the site to GitHub Pages. The project site URL is:

<https://ktosi1994.github.io/ORVEXION/>

You can also start a deployment from the **Actions** tab with **Run workflow**.

The contact form opens a prefilled message in the visitor's email application.
